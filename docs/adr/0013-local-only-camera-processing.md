# ADR-0013: カメラ映像はローカルでのみ処理し、ネットワークに出さない

- ステータス: Accepted
- 日付: 2026-08-16
- 関連: [ADR-0003](0003-parameter-contract.md), [ADR-0012](0012-landmark-based-head-pose.md)

## 背景

Avatar mode の価値のひとつは、生の顔や部屋の映像を相手に送らずに済むことにある。
Realtime のトラッキングと描画はレイテンシに敏感でもあり、クラウドに置く理由が薄い。

## 決定

`getUserMedia` で取得した映像は、ローカルのトラッキングとプレビュー表示にのみ使う。
映像フレームを送信する API は呼ばない。

```text
Camera pixel → local face tracking → raw video を破棄
ネットワークに出るのは、将来的にもレンダリング済みアバター、またはパラメータのみ
```

MediaPipe の WASM と顔モデルは CDN から**取得**する(送信ではない)。
Model Creation(セグメンテーション、レイヤー分解等)は将来クラウドに置く余地があるが、
Model Execution は Edge に置く。

## 影響

- プライバシーが Avatar mode の明確な差別化要素になる
- CDN がブロックされる環境ではトラッキングが起動しないため、スライダーによる代替操作を
  常に残しておく必要がある
- 将来の多人数会議では「自分は 1 トラッキング、他人はパラメータ受信 + ローカル描画」という
  構成が自然に導かれる

## 却下した代替案

- **サーバー側での顔推論**: レイテンシとプライバシーの両面で不利で、毎フレームのクラウド GPU も不要
