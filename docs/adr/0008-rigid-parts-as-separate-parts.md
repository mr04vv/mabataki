# ADR-0008: 剛体として保ちたい要素は別パートに分離する

- ステータス: Accepted
- 日付: 2026-08-16
- 関連: [ADR-0001](0001-key-poses-over-auto-rig.md), [ADR-0004](0004-plain-json-model-format.md), [ADR-0016](0016-occlusion-with-parts-and-masks.md)

## 背景

「前歯は口の開閉どちらでも固定したままにしたい」という具体的な要件が出た。

1 枚のメッシュでは構造的に実現できない。メッシュ変形ではピクセルは自分が乗っている三角形の
頂点に従って動くが、前歯のピクセルが乗る三角形の頂点は口内と共有されている。口を閉じるために
その頂点を動かせば、同じ三角形上の歯も必ず歪む。「歯のセルの頂点を全て止める」と、今度は
歯の周囲の口内が閉じられなくなる。頂点ロック機能を足しても、この綱引きは解消しない。

## 決定

剛体として保ちたい要素は独立した `part` にし、キーフレームを与えない。

- この設計では「動かさない」がデフォルト。デルタが無い頂点は数学的に不動であり、
  固定のための専用機能は不要
- 重なりは `parts` 配列の順序(奥 → 手前)で解決する
- 素材は「同一キャンバスサイズで書き出した複数の透過 PNG」という制作規約になる。
  同一サイズなら原点が揃うため、パーツ間の位置合わせが不要になる。レイヤーを除いた
  背後(歯の裏の口内など)は塗っておく必要がある

## 影響

- モデル形式は当初から `parts[]` 配列なので、形式変更は発生しなかった
- エディタは一度マルチパート対応した後、前歯検証の中断に伴い一旦巻き戻したが、
  その後 `face` / `eyes` / `mouth` の 3 パート構成として正式に採用している
- メガネは独立 Part と4頂点メッシュで追加し、`headYaw` / `headRoll` のみを持たせることで、
  頭部へ追従しながら瞬きの変形から分離できた
- 「閉じた口の中に歯が隠れる」表現が必要になった時点で、クリッピングマスクを追加する
  (現在の絵柄は閉じても前歯が見えるため、描画順だけで成立している)

## 却下した代替案

- **頂点ロック UI のみ**: 三角形を共有する以上、歪みは避けられない。ロックは誤操作防止には
  有効なので、[ADR-0014](0014-editor-features-on-demand.md) の pin 機能として別途採用した
- **グリッドを細かくして歯の周囲の頂点を避ける**: 歯のキワまで閉じられず、品質検証としては妥協が残る
