# ADR-0006: コアは依存ゼロ、リポジトリは単一パッケージにする

- ステータス: Superseded by ADR-0018
- 日付: 2026-08-16
- 関連: [ADR-0005](0005-pixijs-renderer.md), [ADR-0009](0009-renderer-agnostic-runtime-api.md), [ADR-0015](0015-web-first-minimal-runtime.md)

## 背景

`@foo/format` / `@foo/core` / `@foo/webgl` へパッケージを分割する案があった。
一方で PoC 段階では、分割の運用コスト(ビルド、バージョニング、相互参照)に見合う利得がない。

## 決定

単一パッケージ・単一リポジトリで進める。境界は物理分割ではなくディレクトリの規律で守る。

- `src/` — レンダラ・トラッカー・ブラウザ非依存。**実行時依存ゼロ**。公開は `src/index.ts` 経由
- `demo/` — PixiJS / MediaPipe / DOM に依存してよい層
- `package.json` は `private: true`(誤 publish 防止)

## 影響

- 分割の手間なしに、分割の利益(境界の明確さ)だけを先に得られる
- 依存ゼロを保っている限り、後から `@mabataki/core` 等へ切り出す作業は機械的に行える
- 「コアに入れてよいか」の判断基準が明確になる: 特定トラッカー / 特定プロダクト /
  クラウド / AI 推論 / UI フレームワークに依存するものはコアに入れない

## 却下した代替案

- **最初から monorepo 分割**: 利用者がいない段階では運用コストだけが先に発生する
